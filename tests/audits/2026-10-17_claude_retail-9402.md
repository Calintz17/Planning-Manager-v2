## Points d'architecture repris
- **Test de non-régression** (`regression-9402.cjs`) : les règles obligatoires sont comparées clé par clé et par taille, comme `mandatoryAdded`. Une infraction nouvelle n'est plus masquée par une ancienne qui disparaît.
- **SQL** : le test d'existence du CHECK est qualifié par la table (`conrelid`). Rejoué deux fois sur un PostgreSQL 16 vierge.
- **Noms et commentaires** : `monthCapMin` devient `monthReferenceMin`. Le commentaire de `monthHoursUsed` dit maintenant ce que fait le code : il plafonne les crédits, pas les heures travaillées.
