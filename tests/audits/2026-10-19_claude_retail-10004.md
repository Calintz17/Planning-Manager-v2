## Arbitrages de Roman (19-10)
1. **Égalités dans les groupes :** cas normal inchangé (médianes). Si aucun shift ne finit après la médiane des fins (ils finissent ensemble), le soir = ceux qui finissent en dernier et arrivent après la médiane des débuts. Symétrique pour le matin. Un seul shift : pas de groupes, la part ne s'applique pas. Exemple 9h-20h / 10h-20h / 11h-20h → matin / milieu / soir.
2. **Une validation sans retouche compte pour l'apprentissage :** valider = « ce planning est bon ». Sans correction, la part reste près de 50 %. L'apprentissage des corrections à la main (par personne) reste à part et prioritaire.

## Corrections (audit d'Astra)
| Point | Correction |
|---|---|
| P1 futur et mois cible appris | Seuls les mois **avant** le mois calculé (`lt month`) |
| P1 cache par boutique | Cache par boutique **et** mois ; vidé après une validation ou une annulation |
| P2 six lignes, pas six mois | Dernière révision de chaque mois d'abord, puis 6 mois distincts ; un mois dont la dernière révision est annulée ou retirée ne compte pas |
| Historique relu avec l'équipe actuelle | À la validation, le compte du mois (vendeurs du soir, vendeurs connus, version des groupes) est calculé avec l'équipe et les shifts envoyés, et gardé dans `decision_diagnostics`. L'apprentissage lit ces comptes. Les validations faites avant 10.0.0.4 n'en ont pas : elles sont laissées de côté |
| P1 contrôle de la décision | Contrôle avec les données de l'envoi (`context`, chargé avec un envoi en attente) ; le contrôle avec les données du jour est gardé à part (`mandatoryToday`). Jamais de veto |
| P1 provenance des changements | Un changement du réviseur = un shift, un corner ou une absence différent de ce qu'il était à l'envoi (comparé au contexte envoyé), plus « il existe un changement à la main » |
| P2 groupe soir vide | Arbitrage 1 ci-dessus |
| P2 cloche après 50 | Les non-lus sont filtrés sur toute la file (500 au plus) avant d'en montrer 50 |
| P2 compteurs sur téléphone | Même colonne que le Monthly (initiales, nom au toucher), les chiffres tombent sous le 1er jour à 390 et 320 px |
| Aide « Default weekly hours » | La semaine est la limite ; le total du mois est un repère |
| `closing_ratio` | Plus lu ni sauvegardé par la page (colonne en base inchangée) |
| Commentaires | `lateReport` décrit les groupes par médiane |

Les nouveaux textes d'aide restent en anglais dans les autres langues jusqu'au package des langues.
